# 箱梁病害分布图

**[打开在线工具 →](https://mrglll.github.io/box-girder-crack-map/)**

将箱梁裂缝的检查描述整理为五区域病害分布示意图。支持 Excel（`.xls` / `.xlsx`）导入、手动录入、逐条核对，以及按桥、按梁生成 SVG / PNG 和批量成果 ZIP。

## 使用方式

1. 打开上方在线网址，下载 Excel 模板填写，或在页面手动录入。
2. 导入记录，确认梁号、部位、X 位置、裂缝类型、数量和长度。
3. 预览图件，下载单张图片或按桥归档的成果包。项目文件可保存后再次导入，继续核对。

可先点击“载入演示数据”，体验 4 座虚构桥梁、36 根梁、1958 条裂缝的批量处理。

## 在线版说明

公开版通过在线网页提供服务，不提供下载 HTML 后直接离线使用的方式；保存到本机的公开 HTML 会显示在线入口。模板、项目文件和成果图片仍支持下载。

Excel、病害描述和图件在浏览器本机处理，不上传到服务器。当前适用于箱梁裂缝分布示意；X 按梁长定位，裂缝长度经过示意缩放，图件不作为实测几何图。
